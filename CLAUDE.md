# Guitar Theory Lab

See README.md for layout and commands. After every change run `npm test` and `npm run build` (the build regenerates `guitar-theory.html`, the single-file version for opening straight from Finder). Pushing to `main` deploys the site to GitHub Pages (https://rino21111.github.io/guitar-theory/), so only push when asked.

## Design principles

- Less is more.
- Little redundancy: show each thing once, in one place.
- Concise and clear.
- Good UI is the best documentation: let the interface explain itself instead of adding help text.
- No emoji; use simple drawn glyphs or plain text.
- No explanatory paragraphs.
- Playback only ever sounds the strings and frets of the chord's displayed fingering: no added, moved or reached-for notes (no walk-ups, no extra bass notes).
